# 算法教学动画

沿用用户认可的“左侧过程、右侧结构；保存数据始终可见；计算来源可追踪”风格。这是个人Manim工作流，不是固定H2H模板。用户的具体要求优先于以下默认值。

## 呈现默认值

- 深色平面背景，16:9、1080p30、Cairo、无音轨，供用户现场讲解。小例子通常约45–90秒，以数据可读为准。
- 左侧约55%为一个主图／输入／工作状态，右侧约45%为同步增长的树、索引或对应数据结构。其他算法可用数组、堆、矩阵等，不强行套树。
- 默认不加全局标题、顺序条、图例、章节页、解释段落、字幕或装饰图标。保留节点名、边权、集合、保存状态、必要代入式和结果。
- “简洁”去掉辅助说明，**不删除理解计算必需的算法数据**。只有高亮、没有实际值，不能代替标签／状态构建。

先查看[认可参考帧](assets/preview.png)。需要判断节奏时查看[认可成片](assets/reference.mp4)。配色与密度见[视觉规则](references/style.md)。

## 让结构与计算同步可见

先确定输入、状态语义、依赖与预期结果；将算法模型与渲染分开，显示值来自步骤快照／事件，不手写与算法脱离的数字。

左侧删除、压缩或替换对象时，右侧同步显示它留下的结构及必要数据，并在后续使用期间持续保留。用源对象／边权复制或飞入建立映射。未处理的父对象可用灰色虚线占位，之后转为正式节点并保留已有子树。

递推／索引／标签阶段：保留实际读取的权重和已建立的依赖值，不以最终结果覆盖输入；按依赖顺序逐项生成数值，未算项用空位／短横线。关键步骤给出简短实际代入式，并定位输入、来源与结果。辅助边权、全图距离、候选值等不同语义分别定义。

动态过程按真实依赖分阶段维护，变化值继续传播，不变分支停留；不把整棵树一起闪烁当作维护过程，不虚构案例没有的传播链。

## H2H／消除树

任务匹配时读取[H2H语义与数值参考](references/h2h.md)。右树中同时保留：Bag、SC上行边权、后续L标签。SC是消除点到**全部剩余邻居**的权重，包括原边与已有shortcut；经消除点形成的邻居对fill候选不能代替它。建L不覆盖SC；先修复SC再修复L，必要时使二者不同数值同屏。

[可运行参考工程](assets/h2h_reference/)只是一组已验证H2H案例。先复制到任务的新输出目录再运行，不改技能资产。新图必须重算次序、邻接快照、父节点、标签和查询；不能照搬六点答案。其他算法仅借用视觉／组件，不套H2H模型。

## 执行与核验

默认直接做可审阅的第一版，不额外设置分镜批准关卡。缺失关键输入才询问。改已有视频默认另存，保留原稿；仅完成用户要求的范围。

先核验模型，再低清检查关键状态，最后高清导出。数值正确不等于实际画面显示正确。复杂节点变形、中文字体和本机入口见[运行注意点](references/runtime.md)；现有环境可用时不重装依赖。

可用[导出检查脚本](scripts/export_verify.py)规范帧率、检查实际文件并抽帧：

```powershell
python <skill>/scripts/export_verify.py --input <rendered.mp4> --output <new-output.mp4> --sample-times 4 33 58
```

默认无声；用户要求音频时用`--keep-audio`并实现相应音轨。默认不覆盖输出；已授权覆盖时可用`--overwrite`。显式音频、尺寸、时长要求优先。

交付前查看实际成片解码帧：结构增长、对象移除后的保存数据、计算来源与结果、更新前后／不变分支。检查数字、文字、遮挡、连线、媒体流和全片解码。保留源码、必要输入和验证记录；单纯样式修改不重做无关算法测试。

交付以MP4为主，简报时长、分辨率、音频状态、改动与核验范围。教学数值不作性能数据或研究结论。
